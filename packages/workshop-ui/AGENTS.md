# AGENTS.md — packages/workshop-ui

> 桌宠工坊的流程组件与界面。**本包不做结算，不存价格。**
> 上层规则见仓库根 [AGENTS.md](../../AGENTS.md)。

---

## 1. 职责边界

**做**：工坊 8 步流程的界面与状态管理、实时报价展示、生成进度展示、安装引导。

**不做**：结算与扣点、生成任务的实际执行、价格的计算规则。

## 2. 硬性约束（违反即打回）

1. **禁止出现任何价格常量**。不得写 `9.9`、`¥` 后跟硬编码数字、也不得内置折扣率。所有金额只来自 `packages/pricing-sdk` 对 `/v1/quote` 的调用结果。
2. **客户端只预估，服务端才结算**。下单必须带服务端返回的 `quoteId`，服务端复算并比对；`quoteId` 过期或价格变动时，必须提示用户重新确认，**不得静默重试**。
3. **金额显示统一走 pricing-sdk 的格式化函数**，不要在组件里手写 `toFixed`。
4. 所有能力、画风、动作、功能清单**从配置/服务端拉取**，不得在代码里枚举硬编码列表。

## 3. 工坊流程

```
[1 选形象] → [2 选画风] → [3 选动作] → [4 选功能] → [5 语音配置] → [6 报价确认] → [7 生成] → [8 安装到桌面]
```

- 支持**任意步骤回退**，已选内容保留。
- 每一步实时更新右侧「价格明细」与「预计生成时长」。
- 支持「模板一键套用」（预设组合）。
- 价格明细必须**逐项展示**（基础费/画风/动作包/能力包），不得只显示总额。

## 4. 兼容矩阵（AI 极易漏掉，必须人工复核）

风格 × 形象方式 × 动作之间存在**兼容约束**，UI 必须**动态禁用**不兼容项，而不是让用户选完再报错：

- 例：「手绘上传（多帧序列）」不能再套「写实风格」（序列帧不做风格迁移）。
- 兼容规则本身是**配置**，不要硬编码成 if-else 堆叠；从能力配置读取。
- 禁用项要给**可读原因**（如「手绘序列帧不支持写实风格，请改选像素风或卡通风」），不能只置灰。

## 5. 校验与合规提示（属于本包职责）

- 上传图片：格式（JPG/PNG/HEIC）、尺寸、清晰度、人脸/宠物占比校验，不达标给明确提示。
- 上传即触发内容安全审核，不通过需说明原因。
- 肖像权/声音权授权确认必须**显式勾选**，不得默认勾选。
- 生成失败可重试且**不重复扣费**，界面上要明确告知用户。

## 6. 技术约定

- React 19 + Tailwind + zustand。
- 视觉规范见 `DESIGN.md`（设计 token 统一，不各自发挥）。
- 组件不得直接调用 Electron API，走 `preload` 暴露的 contextBridge 接口。
